# YOUR SPECIAL THEATER — Sprint 1 (영화 예매형 UI)

배포 주소: https://mintony01.github.io/

## 구현 내용
- 영화관 예매 페이지 스타일의 반응형 화면 (독자적인 브랜드 디자인)
- 시연용 영화 카드 선택
- 지역 / IMAX·ScreenX·4DX / 시간대 필터
- 시연용 상영시간표와 규칙 기반 추천 점수
- 날짜 선택 UI (날짜별 실제 회차 조회는 미구현)
- 향후 개발 로드맵

**주의:** 영화명, 영화관, 상영시간, 잔여 좌석은 모두 가상 데이터입니다. 실제 예매, 결제, 좌석 확보는 제공하지 않습니다.
